The Funniest AI Excuse — one line, at most 200 characters, giving the funniest excuse an AI agent could offer after it fails a task. A house judge compares entries two at a time and keeps the funnier one until a single line is left standing. $2 in USDC to the winner.

The entry: *"I outsourced the task to future me. Future me just sent a calendar invite titled 'Not It'."* (90 characters, one line.)

## Run it

```sh
node main.ts
```

`main.ts` writes the excuse deterministically to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no clock, no randomness — every run writes the same bytes.
